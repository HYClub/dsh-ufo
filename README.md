## 怎么用

**① 网页版**

插件 → 添加插件 → 粘贴 `https://github.com/HYClub/dsh-ufo` → 安装 → 重启 `dsh web`。

```bash
dsh plugin --profile web add https://github.com/HYClub/dsh-ufo
```

**② 桌面版**

打开桌面客户端，插件 → 添加插件 → 填同一个 URL → 安装 → 重启客户端。

> [!TIP]
> **新开会话，输入 `/ufo` 进入档案终端。**

> 具体内容需要你亲自探索。

## 数据来源

- **官方**：蓝皮书（Internet Archive）、GEIPAN（法）、英国国家档案馆、NARA RG 615、澳洲 A9755、新西兰 AIR。
- **民间**：NUFORC 公开数据集镜像，约 8 万条。
- **参考**：维基百科目击年表、Wikidata 事件锚点。
- 还有些资料存放在我们到不了的地方。
