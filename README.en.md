## How to use

**① Web client**

Plugins → Add plugin → paste `https://github.com/HYClub/dsh-ufo` → Install → restart `dsh web`.

```bash
dsh plugin --profile web add https://github.com/HYClub/dsh-ufo
```

**② Desktop client**

Open the desktop app, then Plugins → Add plugin → paste the same URL → Install → restart the app.

> [!TIP]
> **In a new session, type `/ufo` to enter the archive terminal.**

> The rest is yours to explore.
